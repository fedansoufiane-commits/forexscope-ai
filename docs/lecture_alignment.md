# Abgleich mit den Vorlesungsinhalten

Die bereitgestellten Kursarchive wurden lokal inventarisiert (29 PDF-Dateien
sowie Quiz-, Code-, Audio-, Video- und Poster-Material). Fremde Originaldateien
werden nicht im öffentlichen Repository dupliziert; die fachlichen Konzepte
werden nachvollziehbar in Code, App und Dokumentation umgesetzt.

| Lehrinhalt | Umsetzung in WealthScope AI 1.0 |
|---|---|
| ML-Grundlagen und historische Entwicklung | Modell-Zeitreise von Baseline/Logistic Regression bis Random Forest |
| Klassifikation | Konfusionsmatrix, Precision, Recall, F1, ROC- und PR-Kurve |
| Modelltraining | Median-Imputation und StandardScaler ausschließlich im Training; Pipeline, Regularisierung, Lernkurve, purged Out-of-Time-Test |
| Support Vector Machines | Linear-SVM als Maximum-Margin-Vergleichsmodell |
| Entscheidungsbäume | transparenter Einzelbaum im Benchmark, Erklärung der White-Box-Stärke |
| Random Forests / Ensemble Learning | produktiver Demonstrator, Feature Importance und SHAP |
| Understanding the Data | EDA, Missingness, Korrelationen, Distribution-Shift-Warnung |
| QUA³CK | sichtbare Phasen Q-U-A³-C-K in App, Notebooks und Dokumentation |
| Knowledge Transfer | Streamlit-App, Exporte, Lernstudio und arsnova.eu-JSON |
| KI früher und heute | identisches Testfenster für mehrere Modellgenerationen; Gemini klar vom prädiktiven ML getrennt |

Der Prüfungsleitfaden gewichtet Inhalt, kritische Reflexion und Quellen besonders
stark. Deshalb dokumentiert 1.0 nicht nur ein Ergebnis, sondern auch
Validierungsgrenzen, Modellalternativen, Datenrisiken und Reproduktionsschritte.

Didaktische Referenzen des Lehrenden:

- [arsnova.eu](https://arsnova.eu/de/) - Live-Quiz, Peer Instruction und anonymes Feedback
- [MC Test](https://mc-test.streamlit.app/) - Lern-/Prüfungsmodus und portable Fragensätze
